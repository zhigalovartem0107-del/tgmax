БОТЫ НА СЕРВЕРЕ (работают круглосуточно, телефон не нужен, можно много ботов)
==========================================================================

СКОЛЬКО БОТОВ ВЛЕЗЕТ
  Один бот занимает около 70 МБ памяти.
  Сервер 1 ГБ  — до 8–10 ботов.
  Сервер 2 ГБ  — до 20 ботов.
  Больше ботов — бери тариф с большей памятью, всё остальное то же самое.

1. КУПИ СЕРВЕР
   Timeweb Cloud (timeweb.cloud) или Beget (beget.com) — российские, оплата картой РФ.
   Что выбрать при заказе:
     - Операционная система: Ubuntu 24.04
     - Память (RAM): 1 ГБ для начала, 2 ГБ если ботов будет больше 8
     - Расположение: Москва или Санкт-Петербург
   После оплаты тебе дадут IP-адрес сервера и пароль root (в письме или в панели).

2. ПОСТАВЬ НА ТЕЛЕФОН ПРИЛОЖЕНИЕ Termius (Google Play)
   «+» → New Host: Address — IP сервера, Username — root, Password — пароль. Подключись.

3. ПОДГОТОВЬ СЕРВЕР (один раз). Вставляй по одной строке, жди, пока выполнится:
   apt update && apt install -y python3 python3-venv
   mkdir -p /root/bots
   python3 -m venv /root/bots/venv
   /root/bots/venv/bin/pip install telethon requests

4. ЗАКИНЬ ФАЙЛЫ (один раз)
   В Termius открой SFTP, зайди в папку /root/bots и загрузи с телефона три файла:
     tg_to_max.py, add_bot.sh, tg_to_max@.service
   Потом в терминале:
   cp /root/bots/tg_to_max@.service /etc/systemd/system/
   systemctl daemon-reload

5. ДОБАВЬ БОТА (на каждого бота — одна команда):
   sh /root/bots/add_bot.sh vasya
   (vasya — любое имя латиницей, чтобы ты отличал ботов)
   Скрипт спросит токен бота MAX и ссылку на канал, запустит бота и покажет код привязки.
   Отправь этот код боту в MAX — станешь владельцем. Добавь бота админом в канал MAX.
   Дальше всё — в меню бота в MAX (каналы, расписание, «🔑 Telegram» и т.д.).

   Важно: один токен MAX — один бот. Если этот бот уже работает на телефоне — останови его там.

ПЕРЕНЕСТИ СВОЕГО БОТА С ТЕЛЕФОНА (чтобы не настраивать заново)
   sh /root/bots/add_bot.sh my          — создаст папку /root/bots/my
   systemctl stop tg_to_max@my
   Через SFTP загрузи в /root/bots/my все .json-файлы бота с телефона (с заменой)
   и папку stash_media, если есть. Они лежат в папке, которую бот пишет при запуске:
   «Папка данных бота: ...».
   systemctl start tg_to_max@my

ПОЛЕЗНЫЕ КОМАНДЫ (вместо vasya — имя бота)
   ls /root/bots                              — какие боты есть
   tail -n 30 /root/bots/vasya/bot.log        — что делает бот
   grep КОД -A1 /root/bots/vasya/bot.log | tail -2   — код админа (появляется при каждом запуске)
   systemctl restart tg_to_max@vasya          — перезапустить
   systemctl stop tg_to_max@vasya             — остановить
   systemctl disable --now tg_to_max@vasya    — выключить совсем (папка с настройками останется)
   free -m                                    — сколько памяти свободно

ОБНОВИТЬ ВСЕХ БОТОВ СРАЗУ
   Загрузи новый tg_to_max.py в /root/bots (с заменой), потом:
   systemctl restart 'tg_to_max@*'

ЕСЛИ МНОГО БОТОВ ЧИТАЮТ КАНАЛЫ БЕЗ ВХОДА
   Все они ходят на t.me с одного адреса сервера. Если в bot.log пойдут ошибки 429 или
   «не открывается» у всех ботов сразу — Telegram ограничил частоту. Тогда в меню ботов
   увеличь «⏱ Интервал» (например до 3–5 минут) или подключи аккаунт Telegram («🔑 Telegram»).
