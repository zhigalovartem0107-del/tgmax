TG → MAX: репост из Telegram-каналов в канал MAX
=================================================

ЧТО НУЖНО
  Python 3.9 или новее, библиотеки:  pip install telethon requests
  (в Pydroid: Pip → telethon, requests)

ФАЙЛЫ (положи в одну папку)
  tg_to_max.py   — сам бот
  login.py       — подключить аккаунт Telegram (не обязательно)
  SERVER.txt     — как запустить бота на сервере, чтобы работал круглосуточно
  config.json    — твои ключи и токен. НИКОМУ НЕ ОТДАВАЙ этот файл.
                   Если его нет — бот при первом запуске сам спросит все данные.

ЗАПУСК
  python tg_to_max.py            — запустить бота
  python tg_to_max.py --check    — проверить связь с MAX, Telegram и каналами (бот не запускается)

ПЕРВЫЙ ЗАПУСК
  1. Бот спросит только токен MAX и ссылку на канал. Вход в Telegram НЕ нужен:
     бот читает публичные каналы через t.me (большие видео так недоступны).
     Подключить аккаунт Telegram можно когда угодно потом: в MAX меню бота → «🔑 Telegram»
     (бот спросит api_id, api_hash, номер и код прямо в чате). Или запусти login.py.
     Если Telegram пишет «подождать N часов» — это его ограничение на частые запросы кода.
     Не жми «получить код» много раз подряд.
  2. Привязка владельца. В консоли появится 6-значный КОД ПРИВЯЗКИ (это не код Telegram).
     Открой своего бота в MAX, нажми «Старт» и отправь ему этот код.
  3. Добавь бота админом своего канала MAX (бот найдёт канал по ссылке из config.json).
  4. В меню бота: «📡 Каналы» → добавь каналы Telegram, из которых брать посты.

ХОСТИНГ БОТОВ (Bothost и т.п.)
  - Загрузи tg_to_max.py в репозиторий под именем main.py (главный файл — main.py), рядом requirements.txt.
  - Переменные окружения: BOT_TOKEN (или MAX_TOKEN) — токен MAX, MAX_CHANNEL_LINK — ссылка на канал,
    по желанию MAX_CHAT_ID — числовой id канала, ADMIN_CODE — свой код владельца, TG_PROXY — прокси для t.me.
  - Сервер выбирай ЗА ГРАНИЦЕЙ (Нидерланды): из России Telegram (t.me) заблокирован.
  - Один токен — одна копия бота. Вебхук на токене бот снимает сам.

ПРОДАЖА БОТОВ (меню «💼 Клиенты» — видит только владелец)
  - Клиент даёт токен своего бота MAX → «➕ Новый клиент» → вставить токен → выбрать срок
    (пробный 3 дня / 30 дней — 300 ₽ / 90 дней — 750 ₽). Бот клиента запускается здесь же, у тебя.
  - Панель покажет код привязки — отдай клиенту, он отправит его своему боту и станет владельцем.
  - У клиента: свои темы/каналы/тайник, до 3 тем и 10 источников в теме (меняется в «📏 Лимиты»),
    до 3 админов, без кнопки «🔑 Telegram». В меню видно, до какого числа подписка.
  - За 3 дня и за 1 день до конца бот клиента напоминает продлить; в день окончания — пауза
    (посты не выходят, бот отвечает «продлить — напиши …»), тебе приходит сообщение. Настройки сохраняются.
  - Продление: карточка клиента → «+30 дней» / «+90 дней». Выключить/включить вручную — там же.
  - Каждый бот клиента ~70 МБ памяти: следи за RAM на хостинге.

КАК РАБОТАЕТ
  - Чтобы посты выходили сами, без кнопок: меню → «✋ Одобрение» → выключить.
  - Новый пост в Telegram-канале → карточка у админов: «✅ Сейчас» / «⏰ Через час» / «❌ Пропустить».
  - Если пришло несколько постов сразу — одна карточка на всю пачку.
  - Одобрил один админ — у остальных карточка исчезает; у нажавшего — через 5 минут.
  - «Через час» идёт цепочкой: 12:00 → 13:00 → 14:00.
  - Тайник (🗃): кидай боту мемы (фото, видео, текст). Когда очередь пуста — бот выкладывает оттуда.
  - Темы (🎭): несколько каналов MAX, у каждого свои каналы-источники, подпись, очередь и тайник.
  - Если на ближайший час постов нет — бот пишет об этом (/warn — вкл/выкл).
  - Пост без части вложений не выходит молча: приходит карточка «Повторить / Без вложения / Убрать».
  - 🔥 Тренды (📊 Аналитика → «🔥 Тренды» или /trends): бот сам, в фоне, раз в 2–3 часа на канал ищет свежие
    новости по словам из последних постов канала (библиотека ddgs; запасной путь — RSS Google News), и ИИ строго
    решает, есть ли там ВИРУСНОЕ или очень важное по теме канала. Нет — бот молчит. Есть — короткий сигнал: что
    случилось и почему стоит выложить прямо сейчас. Одна новость (тот же адрес, перепечатка) — один раз:
    память в sent_alerts.json (с резервной копией). Нужны ключи ИИ (Gemini / OpenRouter / DeepSeek).
    Покупателям (host-режим) — только тем, кому включишь: панель → «🧪 Бета-функции» → «🔥 Тренды».
    Переменные: TRENDS=0 — выключить совсем; TREND_AI_DAILY — вопросов ИИ о трендах в сутки (по умолчанию 150,
    бережёт ключи для пересказа постов); TREND_PROXY — прокси для DuckDuckGo, если он недоступен с сервера.
    Строгость: новость должна быть именно про тему канала (слово ниши в заголовке), ИИ сам оценивает вирусность
    (сигнал — только 7–10 из 10; без оценки — только если пишут несколько изданий). Одна и та же новость с других
    сайтов (перепечатка, зеркало) тоже не повторяется. Испортились и файл, и копия — первая проверка молча.
  - ⏱ /perf (админ): где бот тратит время. Медленный MAX не останавливает чтение каналов: отправки и запись
    больших файлов из цикла чтения идут в фоне; нажатия разных людей обрабатываются одновременно.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
  1. python tg_to_max.py --check   — покажет, что именно не в порядке (✅/❌).
  2. В чате с ботом: /check и /log.
  3. Файл bot.log рядом со скриптом — все ошибки с подробностями. Пришли его при обращении за помощью.
