TG → MAX: репост из Telegram-каналов в канал MAX
=================================================

ЧТО НУЖНО
  Python 3.9 или новее, библиотеки:  pip install telethon requests
  (в Pydroid: Pip → telethon, requests)

ФАЙЛЫ (положи в одну папку)
  tg_to_max.py   — сам бот
  login.py       — подключить аккаунт Telegram (не обязательно)
  SERVER.txt     — как запустить бота на сервере, чтобы работал круглосуточно
  config.json    — твои ключи и токен. НИКОМУ НЕ ОТДАВАЙ этот файл.
                   Если его нет — бот при первом запуске сам спросит все данные.

ЗАПУСК
  python tg_to_max.py            — запустить бота
  python tg_to_max.py --check    — проверить связь с MAX, Telegram и каналами (бот не запускается)

ПЕРВЫЙ ЗАПУСК
  1. Бот спросит только токен MAX и ссылку на канал. Вход в Telegram НЕ нужен:
     бот читает публичные каналы через t.me (большие видео так недоступны).
     Подключить аккаунт Telegram можно когда угодно потом: в MAX меню бота → «🔑 Telegram»
     (бот спросит api_id, api_hash, номер и код прямо в чате). Или запусти login.py.
     Если Telegram пишет «подождать N часов» — это его ограничение на частые запросы кода.
     Не жми «получить код» много раз подряд.
  2. Привязка владельца. В консоли появится 6-значный КОД ПРИВЯЗКИ (это не код Telegram).
     Открой своего бота в MAX, нажми «Старт» и отправь ему этот код.
  3. Добавь бота админом своего канала MAX (бот найдёт канал по ссылке из config.json).
  4. В меню бота: «📡 Каналы» → добавь каналы Telegram, из которых брать посты.

ХОСТИНГ БОТОВ (Bothost и т.п.)
  - Загрузи tg_to_max.py в репозиторий под именем main.py (главный файл — main.py), рядом requirements.txt.
  - Переменные окружения: BOT_TOKEN (или MAX_TOKEN) — токен MAX, MAX_CHANNEL_LINK — ссылка на канал,
    по желанию MAX_CHAT_ID — числовой id канала, ADMIN_CODE — свой код владельца, TG_PROXY — прокси для t.me.
  - Сервер выбирай ЗА ГРАНИЦЕЙ (Нидерланды): из России Telegram (t.me) заблокирован.
  - Один токен — одна копия бота. Вебхук на токене бот снимает сам.

🔒 ЗАЩИТА ОТ КРАЖИ (BOT_SECRET) — обязательно
  - Бот запускается ТОЛЬКО с правильным BOT_SECRET. Задай его в переменных окружения хостинга:
    Bothost → Variables (переменные) → BOT_SECRET = <твой секрет>. Без него (или с неверным) бот при старте
    пишет «Unauthorized copy detected» и сразу выходит, не запускаясь.
  - В коде хранится лишь SHA-256 секрета (reloader/services/license.py, строка EXPECTED_SHA256), а не сам
    секрет. Даже если кто-то скопирует все файлы бота, без секрета он их не запустит.
  - Сменить секрет: посчитай хеш нового и впиши в EXPECTED_SHA256:
      python -c "import hashlib; print(hashlib.sha256(b'НОВЫЙ_СЕКРЕТ').hexdigest())"
    затем поставь новый BOT_SECRET в переменных хостинга. Секрет никому не показывай и в репозиторий не клади.

🔒 ЗАЩИЩЁННАЯ (ОБФУСЦИРОВАННАЯ) ВЫКЛАДКА — по желанию, поверх BOT_SECRET
  - Чтобы исходный код было труднее прочитать и разобрать, собери обфусцированную версию через PyArmor:
      pip install pyarmor
      sh build_obfuscated.sh          # положит готовое в папку dist_obf/
  - Загрузи на хостинг ВСЁ содержимое dist_obf/ (вместо исходников), главный файл — main.py. Запуск как обычно:
    python main.py. Не забудь переменную BOT_SECRET — обфускация её не отменяет, замок остаётся.
  - Папки dist_obf/ и файл .bot_secret в репозиторий не попадают (они в .gitignore).

ПРОДАЖА БОТОВ (меню «💼 Клиенты» — видит только владелец)
  - Клиент даёт токен своего бота MAX → «➕ Новый клиент» → вставить токен → выбрать срок
    (пробный 3 дня / 30 дней — 300 ₽ / 90 дней — 750 ₽). Бот клиента запускается здесь же, у тебя.
  - Панель покажет код привязки — отдай клиенту, он отправит его своему боту и станет владельцем.
  - У клиента: свои темы и каналы, до 3 тем и 10 источников в теме (меняется в «📏 Лимиты»),
    до 3 админов, без кнопки «🔑 Telegram». В меню видно, до какого числа подписка.
  - За 3 дня и за 1 день до конца бот клиента напоминает продлить; в день окончания — пауза
    (посты не выходят, бот отвечает «продлить — напиши …»), тебе приходит сообщение. Настройки сохраняются.
  - Продление: карточка клиента → «+30 дней» / «+90 дней». Выключить/включить вручную — там же.
  - Каждый бот клиента ~70 МБ памяти: следи за RAM на хостинге.

КАК РАБОТАЕТ
  - Чтобы посты выходили сами, без кнопок: меню → «✋ Одобрение» → выключить.
  - Новый пост в Telegram-канале → карточка у админов: «✅ Сейчас» / «⏰ Через час» / «❌ Пропустить».
  - Если пришло несколько постов сразу — одна карточка на всю пачку.
  - Одобрил один админ — у остальных карточка исчезает; у нажавшего — через 5 минут.
  - «Через час» идёт цепочкой: 12:00 → 13:00 → 14:00.
  - Темы (🎭): несколько каналов MAX, у каждого свои каналы-источники, подпись и очередь.
  - Если на ближайший час постов нет — бот пишет об этом (/warn — вкл/выкл).
  - Файлы в постах (фото, видео, PDF и др.): сбой Telegram или MAX — бот молча повторяет (скачать из Telegram
    и загрузить в MAX — до 3 раз, коротко). Все файлы загружаются в MAX до первого сообщения поста: пост выходит
    целиком или не выходит вовсе (без «огрызка» без файла). Не вышло — точная причина («File download timed
    out», «MAX upload failed with HTTP 500») только в журнале админа и bot.log; покупателю — ни слова.
  - 🔥 Тренды (📊 Аналитика → «🔥 Тренды» или /trends): бот сам, в фоне, раз в 2–3 часа на канал ищет свежие
    новости по словам из последних постов канала (библиотека ddgs; запасной путь — RSS Google News), и ИИ строго
    решает, есть ли там ВИРУСНОЕ или очень важное по теме канала. Нет — бот молчит. Есть — короткий сигнал: что
    случилось и почему стоит выложить прямо сейчас. Одна новость (тот же адрес, перепечатка) — один раз:
    память в sent_alerts.json (с резервной копией). Нужны ключи ИИ (Gemini / OpenRouter / DeepSeek).
    Покупателям (host-режим) — только тем, кому включишь: панель → «🧪 Бета-функции» → «🔥 Тренды».
    Переменные: TRENDS=0 — выключить совсем; TREND_AI_DAILY — вопросов ИИ о трендах в сутки (по умолчанию 150,
    бережёт ключи для пересказа постов); TREND_PROXY — прокси для DuckDuckGo, если он недоступен с сервера.
    Строгость: новость должна быть именно про тему канала (слово ниши в заголовке), ИИ сам оценивает вирусность
    (сигнал — только 7–10 из 10; без оценки — только если пишут несколько изданий). Одна и та же новость с других
    сайтов (перепечатка, зеркало) тоже не повторяется. Испортились и файл, и копия — первая проверка молча.
  - 📊 Любой канал: перешли боту пост из любого канала MAX (или пришли ссылку t.me/… или max.ru/…) —
    «Вижу пост из канала: …» и три кнопки:
      📊 Рекламный охват — картинка для рекламодателя: сколько просмотров наберёт рекламный пост (вилка
         0,8–1,1 медианы просмотров последних постов), подписчики, ER, приток и отток;
      📈 Массовая проверка — полная аналитика канала, только если он привязан к вашей сетке (иначе бот так и
         скажет: «Этого канала нет в вашей сетке…»);
      ⚡ Оценка потенциала — 0–100: рост, вовлечённость, регулярность постов, размер аудитории.
    В подписи — «Подписалось: +X, Отписалось: -Y, Итого: +Z». Привязывать канал и давать боту права не нужно:
    бот сам раз в час смотрит, сколько подписчиков, и копит приток и отток. «🕘 Недавние проверки» — /recent
    или «📊 Аналитика».
    Открытый канал бот «закрытым» не называет. «Это закрытый канал…» — только для приглашения (t.me/+…,
    max.ru/join/…), если аккаунт Telegram бота в этом канале не состоит. Канал MAX, который MAX не показывает
    боту (бот в нём не состоит), — так и пишет: «MAX не показывает этот канал боту…». Канал Telegram, если t.me
    не открылся или не показал число, бот читает через свой аккаунт Telegram (тот, что читает источники):
    публичный — всегда, закрытый — если аккаунт в нём состоит.
  - 📈 Картинка аналитики приходит БЕЗ подписи, сразу за ней — сообщение в таком виде:
      📈 «Канал»
      👥 5 008 подписчиков · сегодня +11, за 7 дней +83
      👁 Просмотры на пост: 24 ч — 1 145, 48 ч — 1 313, 72 ч — 1 481 · ER24 22,9%
      🤖 Канал растёт, вовлечённость высокая: ER24 выше 20%.
    (у сводки сети — такой блок по каждому каналу; чего не видно — «—»). 4-я строка — вывод ИИ по этим цифрам
    (ключи ИИ — те же, что для пересказа постов, по кругу); те же цифры в течение часа ИИ заново не спрашивают;
    ИИ не подключён или не ответил — три строки.
  - 🧹 Чистый чат: картинки аналитики и сообщения с цифрами остаются в истории (их не удаляет и «час прошёл»).
    Промежуточное — «⏳ Анализирую канал…», «Этого канала нет в вашей сетке…», «MAX не показывает этот канал…»,
    меню канала — убирается после следующего нажатия или когда пришла аналитика (под цифрами — снова меню).
  - 🎨 Картинки аналитики (канал, сеть, прогноз поста, охват, потенциал) — свой дизайн, 1280×800. С 06:00 до
    17:00 по Москве — светлые (тёмный текст), с 17:00 до 06:00 — тёмные (#0A0A0A, белый текст); акценты —
    #9B30FF и #FF1493. Водяной знак — фирменный логотип Reloader (робот и надпись) на чёрной плашке внизу
    справа — на каждой картинке. Фон («📊 Аналитика» → «Фон
    карточек»): 🏞 фото дня — случайное фото с picsum.photos (ключи и регистрация не нужны; одно фото на сутки,
    только с picsum.photos по https, до 8 МБ). Фото видно чётко (горы, лес, небо) под лёгкой вуалью; сверху и снизу —
    мягкое затемнение под текст, под панелями — «матовое стекло» из того же фото. picsum недоступен — запасной
    фон: гранёная сетка (треугольники фиолетового, розового и чёрного с чёткими гранями) — сразу видно, что это не
    фото; снова пробует через 30 минут, причина — в журнале админа. Ещё: 🎨 градиент (сетка без фото), 🤖 рисует ИИ.
  - 🤝 Партнёрская ссылка (для хозяина, без меню для партнёров):
      /partner 123456 — ID партнёра (или переменная хостинга PARTNER_ID); /partner — его ссылка, сколько клиентов
        за ним и сколько они купили; /partner - — убрать;
      /ref — «🔗 Сгенерировать ссылку для клиента»: перешлите боту любое сообщение нового клиента (или пришлите его
        ID в MAX) — в ответ ссылка https://max.ru/<ник бота>?start=ref_<ID партнёра>, клиент закреплён за партнёром.
    Кто пришёл по этой ссылке, тоже закрепляется за партнёром (за первым — второй не перебивает; уже покупавшие до
    ссылки — не в счёт). Купил подписку (ЮKassa, перевод или код активации; промокод 100% — не в счёт) — вам
    сообщение «💰 Клиент [Имя] купил подписку по ссылке партнера [ID]!» с тарифом, суммой и ID клиента; партнёру
    платите сами. Хранится в referrals.json; клиент попросил удалить данные — отметка удаляется.
  - ⏱ /perf (админ): где бот тратит время. Медленный MAX не останавливает чтение каналов: отправки и запись
    больших файлов из цикла чтения идут в фоне; нажатия разных людей обрабатываются одновременно.

⚖️ ЮРИДИЧЕСКОЕ (152-ФЗ, 54-ФЗ, «О защите прав потребителей», «О рекламе»)
  - Реквизиты продавца — /legal (или «💰 Тарифы и реквизиты» → «⚖️ Юридическая информация»), видит только
    владелец: форма (ИП / ООО / Самозанятый), наименование, ИНН и ОГРН/ОГРНИП (проверяются контрольные цифры),
    юридический адрес, почта и телефон поддержки, ссылки на оферту, политику конфиденциальности, условия возврата
    и политику cookie. То же можно задать переменными хостинга (введённое в панели главнее): LEGAL_FORM,
    LEGAL_NAME, LEGAL_INN, LEGAL_OGRN, LEGAL_ADDRESS, SUPPORT_EMAIL, SUPPORT_PHONE, OFFER_URL, PRIVACY_URL,
    REFUND_URL, COOKIES_URL. В панели «-» очищает поле.
  - Перед любой оплатой покупатель отмечает «✅ Я согласен с условиями Оферты и Политикой конфиденциальности»
    (по умолчанию не отмечено). Без отметки ни ссылки ЮKassa, ни заявки на перевод. Согласие хранится с датой и
    версией документов (legal_consents.json); поменялись оферта, политика, возврат или продавец — спросит заново.
  - Цена на экране = цене в ЮKassa и в чеке; карта не привязывается, автосписаний нет. Заявку бота клиента
    с ценой не по тарифу продавец не принимает.
  - У покупателя: «📄 Условия» и «❓ Поддержка» — документы и реквизиты; «🔐 Какие данные хранит бот» (что, зачем,
    кому передаётся); «🗑 Запросить удаление моих данных» — запрос приходит владельцу с кнопкой удаления, после
    удаления покупателю — подтверждение (по закону — в течение 30 дней). В рекламе — «🔕 Не присылать рекламу».
  - Тексты оферты и политики пишешь ты (лучше с юристом) — бот показывает твои ссылки. Это не юридическая
    консультация.
